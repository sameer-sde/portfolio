## ✨ Features

- ⌘K **Command Palette** — search sections, projects, and links instantly
- 🌍 **Interactive Tech Globe** — 3D rotating sphere of my tech stack
- 🎨 **Animated Gradient Mesh** — dynamic background with floating color blobs
- 🖱️ **Custom Cursor** with glow effect and trail
- 🧲 **Magnetic Buttons** — buttons pull toward your cursor
- 🃏 **3D Card Tilt** — project cards rotate in 3D on hover
- 🔤 **Typing Animation** — cycles through roles in the hero
- 📊 **Animated Skill Bars** — colorful gradient bars per language
- 🎯 **Section Progress Dots** — right-side navigation dots
- 📈 **Stats Ticker** — scrolling achievement highlights
- 👋 **Hire Me Banner** — slides up after 8 seconds
- 🎮 **Konami Code Easter Egg** — try ↑ ↑ ↓ ↓ ← → ← → B A
- 📋 **Copy Email** — one-click clipboard copy
- 📱 **Fully Responsive** — mobile optimized

## 🛠️ Tech Stack

Built with zero frameworks — pure HTML, CSS & JavaScript.

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 |
| Styling | CSS3 (Custom Properties, Grid, Flexbox, Animations) |
| Interactivity | Vanilla JavaScript (ES6+) |
| 3D Globe | Canvas API |
| Fonts | Inter · JetBrains Mono · Playfair Display |
| Deployment | Vercel |
